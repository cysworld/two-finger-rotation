# 反馈与贡献 / Feedback and contributions

## 中文

- **欢迎反馈**：使用中遇到的问题、识别不准的情况、改进建议，都可以在 Issues 里提出。描述识别问题时，附上轨迹录制文件（见 [docs/design.md](docs/design.md) 第 13 节）会很有帮助。
- **不接受代码合并请求**：本项目采用双重授权（GPL-3.0 和商业授权），所有代码需要由作者本人持有版权，所以不接受外部提交的代码（Pull Request）。如果你有修改想法，请在 Issue 里描述，作者会自己实现。

## English

- **Feedback is welcome**: report problems, misrecognized gestures and suggestions in Issues. For recognition problems, a recorded trace (see section 13 of [docs/design.md](docs/design.md), Chinese) helps a lot.
- **No pull requests**: the project is dual-licensed (GPL-3.0 and commercial), so the author must hold the copyright to all code. External code contributions are therefore not accepted. If you have an idea for a change, describe it in an issue and the author will implement it.
